# Xilinx Clocking Wizard v6.0（PG065）中文入门笔记

> 对象：Vivado 初学者、Zynq-7020（Zynq-7000）用户。依据 Xilinx《Clocking Wizard v6.0 Product Guide PG065》，文档版本日期 2022-04-20。本文把手册事实与工程理解分开标记；实际可用频率、VCO 范围、端口和 GUI 选项要以所选器件、Vivado 版本及生成的 IP 为准。

## 1. 先用一句话理解它

Clocking Wizard 是 Vivado 的时钟配置向导。你告诉它输入时钟频率、希望得到的输出频率/相位/占空比和所需功能，它为 FPGA 内部的 MMCM 或 PLL 生成配置及配套 RTL/XDC。它不是外部振荡器：它需要一个真实、稳定的输入时钟，不能凭空产生板外时钟源。

**手册说明：** IP 支持 Zynq-7000 SoC 与 7 Series，可配置时钟网络、生成 RTL，并提供示例设计和仿真 testbench；至少要有一个输入和一个输出时钟。向导可自动选择/配置原语，也允许高级用户覆盖参数。

**实践理解：** Zynq-7020 的 PL 时钟常见来源是板上晶振经 PS/FCLK 或 PL 时钟引脚进入设计。先确定实际接到 `clk_in1` 的信号和频率，再配置 Wizard。Clocking Wizard 管的是 PL 时钟，不等于 PS 内部处理器时钟配置。

## 2. 必须认识的概念

| 术语 | 通俗解释 |
|---|---|
| 输入时钟（input clock） | 送入时钟网络的参考节拍，例如 100 MHz。频率应与板级/上游实际输出一致。 |
| 输出时钟（output clock） | Wizard 生成的 `clk_out1`、`clk_out2` 等，可有不同频率、相位或占空比。 |
| MMCM | 混合模式时钟管理器；能做频率合成、相位等高级时钟处理。 |
| PLL | 锁相环；同样可倍频/分频并跟踪输入时钟。是否选择由器件和需求决定。 |
| VCO | MMCM/PLL 内部振荡器。倍频后要落在器件规定的 VCO 有效范围内。 |
| 锁定（lock） | 环路已收敛到输入参考；`locked=1` 表示可认为输出时钟稳定可用。 |
| 反馈（feedback） | 把输出相关信号送回原语，供它校正相位/延迟。相位对齐需求下尤其重要。 |
| 抖动（jitter） | 时钟边沿相对理想位置的短期时间偏差。输入抖动会影响输出质量。 |
| 相位（phase） | 时钟边沿相对参考或其他输出的时间偏移；180°表示半个周期。 |
| 占空比（duty cycle） | 一个周期中高电平所占百分比；50% 表示高、低各半周期。 |
| 安全启动（Safe Clock Startup） | 在锁定后通过缓冲控制，延迟开放输出时钟，减少不稳定启动时钟传入下游。 |
| 动态重配置（Dynamic Reconfiguration） | FPGA 运行时改动时钟原语参数；不是普通初次上电配置，涉及 AXI4-Lite 或 DRP 控制。 |

## 3. 频率计算：理解向导背后的算术

### 常用公式

定义：

- `Fin`：输入时钟频率
- `D`：输入分频（`DIVCLK_DIVIDE`）
- `M`：反馈倍频（`CLKFBOUT_MULT` 或带小数的 `_F` 参数）
- `O`：某个输出分频（`CLKOUTx_DIVIDE`）
- `Fvco`：VCO 频率

公式：

```text
Fvco   = Fin × M / D
Fout_x = Fvco / O = Fin × M / (D × O)
```

### 手算例子

输入 `Fin=100 MHz`，取 `D=1`、`M=10`：

```text
Fvco = 100 × 10 / 1 = 1000 MHz
```

若输出分频 `O=5`：

```text
Fout = 1000 / 5 = 200 MHz
```

该数值计算本身不代表配置一定合法：必须再确认 **1000 MHz 落在所选 Zynq-7020 对应原语的 VCO 允许范围内**，输入、输出以及时钟缓冲器频率也符合器件规格。PG065 的 AXI 示例也用 100 MHz 输入、VCO 1000 MHz、输出 200 MHz 演示重配置。

### 频率设置的实际限制

**手册说明：** Wizard 会尽量匹配要求；若找不到精确解，会显示 best-attempt（尽力而为）数值。输出优先级为 `clk_out1 > clk_out2 > clk_out3 ...`；频率优先于相位，相位优先于占空比。手册建议完整填写输入参数，像 33⅓ MHz 应写 33.333 MHz，而不是 33 MHz。

**实践理解：** 配多个输出时，不要只看输入框里的期望值。生成后查看 Output Clock 的实际值，以及 IP 的时钟摘要/约束；还要检查实现报告的时钟和时序。若某一路最重要，把它作为优先输出并先满足它。

7 系列 MMCM 的分数分频在特定路径上可按 0.125 步进使用，但会有约束（例如分数模式下占空比不可编程，且一些相移模式不可用）。初学者优先用整数分频；需要分数分频时以对应器件手册和向导校验结果为准。

## 4. 常用端口与信号

最终端口取决于 GUI 勾选的功能。未启用的可选端口通常不会出现在顶层接口；请以生成的 stub/template 为准。

| 信号 | 方向 | 用途与注意点 |
|---|---|---|
| `clk_in1` | 输入 | 主参考时钟，单端版本。差分输入时可能是 `clk_in1_p/n`。 |
| `clk_in2`、`clk_in_sel` | 输入 | 可选第二参考时钟及选择控制；只有配置双输入时才有。按端口表确认选择电平含义。 |
| `clk_out1`、`clk_out2`… | 输出 | 生成时钟；实际可用路数受器件和原语限制。Zynq-7000 的 PLLE2 最多六路，MMCM 可更多；最终看 GUI/IP。 |
| `reset` / `resetn` | 输入 | 可配置为高有效或低有效复位。PG065 推荐设计中优先使用高有效 reset。复位会异步清内部状态，释放后重新锁定。 |
| `locked` | 输出 | 高表示输出时钟稳定、可供下游使用。复位、输入时钟中断或重配置期间应视为未就绪。 |
| `clk_outX_ce` | 输入 | 选用支持 CE 的输出缓冲时出现，用于使能该缓冲输出。不是通用时钟门控替代品。 |
| `clk_outX_clr` | 输入 | 部分分频缓冲器的计数器清零端，只有相应 buffer 配置下出现。 |
| `power_down` | 输入 | 可选低功耗控制；有效时停止输出时钟。 |
| `input_clk_stopped` | 输出 | 可选状态，提示所选输入时钟停止。时钟监控功能还可提供监测信号。 |
| `psclk`、`psen`、`psincdec`、`psdone` | 输入/输出 | 动态相移握手信号；仅启用动态相移时使用。 |
| `daddr`、`dclk`、`den`、`di`、`do`、`drdy`、`dwe` | 输入/输出 | 原语 DRP 动态重配置接口；应按手册协议时序操作。 |
| `s_axi_*` | 输入/输出 | 选择 AXI4-Lite 动态重配置接口时出现；软件/主机通过寄存器改时钟参数。 |

## 5. 在 Vivado 中配置 Zynq-7020 的基本流程

### A. 建立工程和 IP

1. 新建工程，器件选择实际板卡上的 Zynq-7020 型号/封装/速度等级；或选择准确的 Board Part。
2. 在 IP Catalog 中添加 **Clocking Wizard**，打开 Customize IP。
3. 在输入时钟页确认 `clk_in1` 来源、单端/差分、输入频率和抖动。不要按示例默认值猜测板上时钟。
4. 选择所需时钟功能与原语策略。一般初学者先用向导推荐的 MMCM/PLL，不手工覆盖原语参数。
5. 在输出时钟页逐个启用输出，填频率、相位、占空比；查看向导给出的实际值。确认需要的输出缓冲器适用于目标频率。
6. 仅在确有需求时启用 Safe Clock Startup、Clock Sequencing、动态相移或动态重配置等高级功能。开启会增加接口/逻辑与验证工作。
7. 检查 Optional Ports、reset 极性，生成 IP Output Products。
8. 在顶层连接输入时钟、复位、输出时钟及 `locked`。给输入时钟添加正确 XDC 时钟约束，确认 IP 生成约束被工程纳入。
9. 综合、实现，查看时钟与时序报告；确认输入时钟来源、频率、输出时钟和下游时序均符合预期。

### B. 常见连接思路

```text
板上时钟 / PS FCLK
        │
        ▼
clk_wiz_0.clk_in1 ── Clocking Wizard ── clk_out1 ── 下游逻辑时钟
                           │
                           └── locked ── 下游复位控制/就绪逻辑
```

**工程建议（非 PG065 强制规定）：** 下游模块的复位释放最好与 `locked` 协调，并在下游时钟域做同步释放；复位断言可按系统策略异步或同步处理。不要把 `locked` 当作数据通路时钟，也不要只在仿真中假设它立即变高。具体复位同步方式应遵循整个工程的复位架构。

## 6. Reset 与 locked：上板前务必理解

- **手册说明：** `reset/resetn` 有效会异步清除原语内部状态；撤销复位后，原语重新执行锁定序列。
- **手册说明：** `locked=1` 表示输出时钟稳定且可用。复位后应等待锁定再依赖输出。
- **手册说明：** 若所选输入时钟停止，`input_clk_stopped` 可提示停止；该信号恢复后仍需施加 reset（按手册所述时钟停止检测相关流程）。
- **实践解释：** 输入时钟异常、复位一直有效、输入频率填错、VCO 组合越界、时钟引脚/约束错误，都可能导致永远锁不上或锁定不稳定。
- **实践解释：** 若 `locked` 拉低，建议让使用该时钟的下游逻辑回到安全复位状态；恢复后重新等待 `locked`，避免逻辑在不稳定时钟下运行。
- **实践提醒：** reset 极性必须和实际连线一致。若 IP 配成 `reset` 高有效，却接了低有效复位而未反相，IP 会表现得像一直复位或复位失灵。

## 7. 仿真与调试检查清单

### 仿真

- [ ] 输入时钟 testbench 按实际频率持续翻转，复位按设计极性正确施加并释放。
- [ ] 使用 Vivado 支持的 Xilinx 仿真库与器件原语模型。**Zynq-7000/7 Series 不支持手册提到的 UNIFAST 快速库；使用 UNISIM。**
- [ ] 波形中检查复位释放、`locked` 拉高时间、输出频率/相位/占空比。
- [ ] 对多输出设计逐路测周期；不要只凭波形视觉判断频率。
- [ ] 需要参考时，可运行 IP 的 `open_example_project` 示例与 testbench；手册描述 testbench 会计算输出频率并报告不符合项。
- [ ] RTL 仿真模型会抽象真实模拟锁相过程；仿真通过不等于板上输入时钟、电源和时序一定正确。

### 综合、实现与上板

- [ ] 确认工程包含正确的输入时钟 XDC 约束和 IP 约束；时序约束完整且实现无未解释的时序违例。
- [ ] 核对板级输入时钟确实存在、频率正确且质量合适；用示波器/频率计或已知设计验证时钟源。
- [ ] 查看 `locked`；不要在锁定前认为输出已稳定。可用 ILA/VIO 观测控制状态（注意 ILA 自身时钟要可靠）。
- [ ] 如果输出变成 0 或异常，PG065 提醒先检查相关约束/锁定，也提及检查 licensing；普通 Clocking Wizard 通常无需 FLEX license，结合实际 Vivado/IP 状态判断该条提示。
- [ ] 检查选定输出 buffer 的最大频率限制与实际输出频率是否匹配。
- [ ] 动态重配置时，重新核算 VCO：`Fin × M / D`；确认设备 VCO 范围及分数使能位只在分频参数确实为非整数时设置；完成后等待重新锁定。
- [ ] 若仿真正常但上板异常，继续检查板级时钟源、电源完整性、引脚/时钟能力和 PCB 信号质量。

## 8. 动态重配置是进阶功能

PG065 描述两种访问思路：AXI4-Lite 配置寄存器，或直接使用 DRP。AXI4-Lite 示例中，先写新参数、检查状态，再发起加载，最后等待 `locked`。直接 DRP 需要按器件原语协议组织读写事务。

**实践建议：** 初学者如果只是开机后固定输出几路时钟，不要开启动态重配置。动态改分频会让输出频率改变，若下游逻辑没有暂停、复位和重新同步策略，可能导致数据损坏。若确实要运行时改时钟，先阅读 PG065 对应寄存器/握手章节及 XAPP888，并为每次切换设计完整的下游安全流程。

## 9. 常见误区

1. **“设置 100 MHz 输出就必定得到精确 100 MHz。”** 向导可能只能给尽力而为值；还要看实际值和器件限制。
2. **“`locked` 一直高，时钟就永远可靠。”** 输入停止、复位和重配置都可能影响锁定；系统要处理状态变化。
3. **“复位撤销后立刻能用输出。”** 还需要等待 MMCM/PLL 重新锁定。
4. **“一个时钟 IP 能替代板上晶振。”** 它需要输入参考时钟。
5. **“`clk_out1` 就是 MMCM 原语的 CLKOUT0。”** 逻辑端口名和原语内部输出编号不是简单同名对应；看生成配置，不要仅凭名称推断。
6. **“手册示例的数值适合所有芯片。”** VCO、输入和缓冲器限制随器件变化；7020 要以其数据手册与 Vivado 校验为准。

## 10. 术语缩写表

| 缩写 | 全称 | 记忆方式 |
|---|---|---|
| AXI4-Lite | AXI4 Lite 接口 | 简单寄存器读写接口，适合由处理器控制动态重配置。 |
| DRP | Dynamic Reconfiguration Port | 直接访问 MMCM/PLL 动态配置寄存器的端口。 |
| XDC | Xilinx Design Constraints | Vivado 时序/引脚等约束文件。 |
| UI | Unit Interval | 单位间隔；常用于把抖动按时钟周期比例描述。 |
| PS | Picosecond | 皮秒；抖动输入也可用绝对时间单位表示。 |
| RTL | Register Transfer Level | Verilog/VHDL 硬件描述代码层级。 |
| ILA | Integrated Logic Analyzer | FPGA 内部逻辑分析仪，可在硬件运行时抓信号。 |
| VCO | Voltage-Controlled Oscillator | MMCM/PLL 内部振荡器，须处于器件规定范围。 |
